# Generate a blank CSV inventory template

Generate a blank CSV inventory template

## Usage

``` r
generate_csv_template(output_file, include_examples)
```

## Arguments

- output_file:

  Character. Path to write the template CSV to.

- include_examples:

  Logical. If TRUE (default), includes one example row per source to
  illustrate the expected format. If FALSE, writes header only.

## Value

Invisibly, \`output_file\`.
