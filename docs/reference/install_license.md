# Install a residencyR license file

Install a residencyR license file

## Usage

``` r
install_license(license_text, path)
```

## Arguments

- license_text:

  Character. The full contents of a license file, exactly as issued at
  purchase or renewal.

- path:

  Character or NULL. Where to install it. Defaults to the standard
  per-user location.

## Value

Invisibly, the path the license was written to.
